Value stream — how an audit runs (executive summary)

  1. User opens the Web UI and signs in via OIDC.
  2. API checks rights with Casbin, stores metadata in PostgreSQL, files in MinIO.
  3. API places a job on Redis; a Taskiq worker picks it up.
  4. Worker calls the external Inference VLM, writes fields/rules to PostgreSQL.
  5. Progress flows Redis → SSE → Web UI so the user sees live status, then the final report.
