# Repody design system

Read before any UI work. Audit and plan: `docs/design/app-redesign.md`.

## Direction: a live ledger

Dense, crisp, alive. A reviewer's desk where every document has its colour, every judged thing has
its glyph, and the screen moves only to tell you something changed. Linear's method (inverted L
chrome, keyboard first, hierarchy by brightness, rows not cards), our own character.

Liveliness comes from information, never decoration:
1. **Document colours.** Each document type of a workflow gets a hue (`--doc-1` to `--doc-8`, same
   lightness and chroma as the accent, generated by the theme). Its chip, dot and A/B mark use it in
   the builder, rules, runs and report.
2. **Status everywhere.** The status glyph (`components/ui/status-glyph.tsx`) on every judged thing,
   pass/warn/fail washes on rows that need attention, inline micro-bars for rates and volumes.
3. **Live data.** Running runs pulse, new rows slide in, numbers tick, counts sit in the sidebar.
4. **Grouped lists.** Sticky group headers (Aujourd'hui, Hier, Cette semaine) with counts.
5. **Hover reveals.** Row actions and shortcuts appear on hover; hovering prefetches the detail.

## Components

Behaviour comes from **ui-sdk** (`@ui-sdk/react/*`, see AGENTS.md and the ui-sdk skill): dialogs,
menus, selects, comboboxes, tabs, tooltips, toasts, command, checkbox, switch, segmented control,
resizable, scroll area. Our styled wrappers live in `components/ui/`. Never hand-roll a `role=`.

## Tokens (generated by `lib/theme/generate.ts`, never hard-coded)

- Surfaces: `canvas` (chrome) < `panel` (content) ; `raised`, `overlay`, `field`.
- Ink: `ink`, `ink-2`, `ink-3`, `ink-4`. Lines: `line`, `line-strong`. Washes: `hover`, `selected`.
- Accent: `accent`, `accent-hover`, `accent-ink`, `accent-wash`, `on-accent`, `focus`.
- Status: `pass|warn|fail` with `-ink` and `-wash`. Documents: `doc-1..8` with `-ink` and `-wash`.
- Brand per deployment: `REPODY_BRAND_NAME`, `_LOGO_URL`, `_BASE`, `_ACCENT`, `_CONTRAST`, `_RADIUS`.

## Type

Inter (optical sizing), `cv01` `ss03`. Weights 400 / 510 / 590.

| Role | Class | Use |
|---|---|---|
| Hero | `text-[22px] font-semibold tracking-[-0.02em] tabular-nums` | One per screen: the verdict, the number |
| Title | `text-[15px] font-semibold` | Header bar, dialog titles |
| Section | `text-[13px] font-semibold` | Group headers |
| Body | `text-[13px]` | Rows, controls |
| Meta | `text-xs text-ink-3 tabular-nums` | Counts, times, ids |
| Mono | `font-mono text-xs` | Keys, values, code |

## Density

Rows 32px (lists), 36px (settings). Controls 28px (`h-7`) in toolbars, 32px in forms. Header 40px.
Sidebar 224px, collapsible (`[`). 8px inside a group, 16px between groups, 32px between sections.
Lists bleed edge to edge; reading pages max 1080px. No section opens with more than 32px of void.

## Motion (`motion/react`, `MotionConfig reducedMotion="user"`)

Ease `cubic-bezier(0.23, 1, 0.32, 1)`; springs bounce 0. Presets in `lib/motion.ts`.
Rows enter 180ms, 20ms stagger, 8 max. New row slides in plus a 1.2s accent wash. Status glyph
morphs (spring 300ms). Peek panel 200ms from the right. Dialog 200ms in, 120ms out, scale 0.96.
Menus 150ms from the trigger (`origin-(--transform-origin)`). Selection bar rises (spring 250ms).
Extracted value lands: fade 160ms plus a status wash 800ms. Tabs: shared underline (`layoutId`).
Numbers tick 300ms. Never animate keyboard-repeated actions or page transitions.

## Speed

Keyboard map (`lib/hotkeys.ts`): `J`/`K` and arrows move, `↵` open, `Esc` back, `Space` peek,
`X` select, `C` create, `F` filter, `/` search, `G` then `O`/`W`/`R`/`S` go to, `[` sidebar,
`⌘K` palette, `?` shortcuts. Writes are optimistic (React Query `onMutate`, rollback on error).
Hover prefetches. Skeletons match the final rows and wait 150ms before showing.

## Never

Gradients, glows, blur on content, coloured shadows, icon tiles, uppercase tracked labels, more
than one accent for actions, `transition-all`, raw palette classes (`bg-gray-*`, hex) in components,
an empty page region larger than the content beside it.
